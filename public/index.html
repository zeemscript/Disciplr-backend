Disciplr API

Commitment vaults on Stellar. Lock funds against milestones, a verifier validates progress, funds release on success or redirect on failure.

OpenAPI specHealthGET /api/vaultsSource
Status: checking...

Endpoints

GET/api/health service and active data store
GET/api/vaults?creator=&status= list vaults
POST/api/vaults create a vault with milestones
GET/api/vaults/:id vault detail with activity
POST/api/vaults/:id/milestones/:mid/validate verifier validates a milestone
POST/api/vaults/:id/fail verifier fails a vault, funds redirect
GET/api/transactions activity feed
GET/api/stats aggregate statistics

Example

curl -X POST $BASE/api/vaults -H 'content-type: application/json' -d '{
  "creator": "G...56 chars", "verifier": "G...56 chars", "amount": 500,
  "endDate": "2027-01-01",
  "milestones": [{"title":"Ship v1","amount":250},{"title":"Launch","amount":250}]
}'

Public demo API: no authentication; the verifier address in the request body authorises validation. Settlement is simulated; see the README for the on-chain contract status.
